# Mimic Chests Mod

![Mimic Chests Banner](https://example.com/banner.png)  
*A thrilling Minecraft mod where chests might just bite back!*

## 🗝️ About the Mod
**Mimic Chests** adds mysterious living chests to Minecraft. At first glance, they appear as ordinary treasure chests, but beware! Some of them are hungry and will strike when you least expect it.

## 🎮 Features
- **Mimic Entities** – Chests that transform into hostile monsters when opened.
- **Custom Animations** – Legs move dynamically when the Mimic moves, similar to *The Aether*'s hostile chests.
- **Treasure or Trouble?** – Some chests contain real loot, while others contain... *teeth.*
- **Smart AI** – Mimics can detect nearby players and attack strategically.

## 🛠️ Installation - Mod is still in its devlopment phase.

## ⚔️ Gameplay
- Right-clicking on a Mimic Chest may trigger it to attack!
- Mimics drop **rare loot** upon defeat.
- Some Mimics have **special abilities** depending on their biome.
